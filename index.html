Enterprise Systems Deployment

Geographic Network Monitoring System

Led the deployment of a real-time GNMS for the Ikeja Electric sub-grid. Integrated a Data Aggregation System (DAS) with meter headend systems to feed ArcGIS via GeoEvent Server. Replaced manual status checks, providing real-time visibility into feeders and distribution transformers, which shortened fault response times by at least 3 hours.

Domain: Real-Time Dashboards, GeoEvent Server, Enterprise Integration
