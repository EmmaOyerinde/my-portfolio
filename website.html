Geographic Network Monitoring System

A real-time GNMS developed for the Ikeja Electric sub-grid. By utilizing a Data Aggregation System (DAS) to fetch data from meter headend systems to ArcGIS via GeoEvent Server, this system replaced cumbersome manual status checks. It provides granular views of feeders, interconnected DTs, and real-time remote terminal device parameters, helping maintenance engineers shorten fault response times by at least 3 hours.

Tools: ArcGIS Dashboards, Hub, Experience Builder, Online, Pro, GeoEvent Server

Spatial Analysis

UNDP Ukraine: Just Transition of the Coal Cities

Generated GIS-based maps to analyze environmental conditions and parameters affecting coal-mining areas in the Donbas region. This spatial analysis helped identify areas of concern to support evidence-based decision-making for local transition planning as Ukraine phases out coal by 2035. The outputs contributed to broader UNDP efforts like decentralized energy development, green financing, and sustainable employment.

Tools: ArcGIS Pro
